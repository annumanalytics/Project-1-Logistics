# Project 1: Logistics

## Executive Summary 
This projects solves critical facility location challenges for expanding enterprise systems. By utilizing advanced Mixed-Integer Linear Programming (MILP), the model identifies the absolute lowest-cost cities to position distribution hubs while fully satisfying consumer geographic demand and strict capital budgeting caps. 

## Modelled Business Impact 
* **Cost Minimization:** Strategic site location allocation reduces simulated total network distribution expenses by **X-Y%** relative to basic proximity-based choices.
* **Supply Chain SLA Continuity:** Realizes a 100% total system order delivery fulfilment rate under tight simulated capacity limits.

## Tech Stack & Architecture 
* **Core Language:** Python 3.10+
* **Mathematical Optimization Solver:** PuLP (COIN-OR CBC Engine)
* **Frontend Analytics Dashboard:** Streamlit UI Framework
* **Data Processing:** Pandas & NumPy arrays

## How to Run Locally
1. Clone this project repository to your workspace.
2. Install the production requirements: 'pip install -r requirements.txt'
3. Launch the visual analytics engine: 'streamlit run src/app.py'
